# dpsmpx

**C++ / Python developer focused on game development, procedural systems, simulations and AI-assisted tools.**

I build small experiments and larger projects around systems that are fun to model, render and test — from cellular automata and evolutionary algorithms to Android games and semantic tools.

## Current projects

### 🎮 [3D Voxel OpenWorld RPG](https://github.com/dpsmpx/3D_Voxel_OpenWorld_RPG)
A voxel action-RPG for Android built from scratch with **C++20, Vulkan 1.1 and Android NDK**.
Procedural world generation, combat, NPCs, weather, day/night cycles and dynamic lighting.

### ⚔️ [Andors-Love](https://github.com/dpsmpx/Andors-Love)
A turn-based RPG in **C++11** with both a terminal interface and an **SDL2** interface.
Custom combat mechanics, quests, dialogue, equipment and a shared game core.

### 🌱 [DP_Ecosystem](https://github.com/dpsmpx/DP_Ecosystem)
A **Python + Pygame** ecosystem simulation with water, plants, herbivores, predators, reproduction, weather and day/night cycles.

### 🧩 [PixRogue](https://github.com/dpsmpx/PixRogue)
A mobile-friendly **Python + Pygame** interpretation of the classic Rogue formula: procedural dungeons, exploration, hunger, traps, items and monsters.

## Tools & experiments

- [DP_Graph_Builder](https://github.com/dpsmpx/DP_Graph_Builder) — offline formula parser and interactive graphing tool for Android and desktop.
- [DP_GD_Python](https://github.com/dpsmpx/DP_GD_Python) — procedural motorcycle tracks with simulation-based difficulty generation.
- [DP_Gen_Bots](https://github.com/dpsmpx/DP_Gen_Bots) — evolutionary bots with genomes, mutation, crossover and fitness-driven selection.
- [DP_3D_Works](https://github.com/dpsmpx/DP_3D_Works) — experimental 3D rendering algorithms and voxel-like geometry.
